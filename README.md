## Overview

Recipe Browser adds a searchable in-game catalog to Terraria displaying every crafting recipe, the required crafting station, ingredient quantities, and which recipes consume a given item as a component. It eliminates the need to alt-tab to the Terraria wiki and supports all recipes added by installed content mods.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Recipe Browser** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Recipe Search** | Search any item name to instantly display its complete crafting recipe |
| **Station Filter** | Filter recipes by crafting station to see what each bench produces |
| **Ingredient Lookup** | See every recipe that uses a given item as a crafting ingredient |
| **Mod Recipe Support** | Automatically indexes recipes added by all installed Terraria mods |
